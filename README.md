# 🌍 لغتي — موقع تعلم اللغات الذكي

موقع تفاعلي لتعلم اللغات مع مساعد ذكي مدمج يعمل بالكامل في المتصفح.

## المميزات

- ✅ اختبار مستوى ذكي يحدد مستواك بدقة
- ✅ خطة تعلم مخصصة حسب مستواك
- ✅ 6 لغات متاحة (إنجليزية، فرنسية، إسبانية، ألمانية، يابانية، صينية)
- ✅ مساعد ذكي يجيب عن أسئلتك ويقدم نصائح
- ✅ تتبع التقدم والإحصائيات
- ✅ تصميم متجاوب يعمل على جميع الأجهزة
- ✅ وضع داكن تلقائي
- ✅ حركات وتفاعلات احترافية
- ✅ يعمل بدون خادم — كل شيء في المتصفح

## طريقة التشغيل

### محلياً:
1. افتح مجلد المشروع
2. افتح ملف `index.html` في المتصفح
3. ابدأ التعلم!

### على استضافة مجانية:
1. ارفع محتويات المجلد إلى أي استضافة مجانية:
   - GitHub Pages
   - Netlify
   - Vercel
   - Cloudflare Pages
2. الموقع سيعمل مباشرة بدون أي إعدادات

## التقنيات المستخدمة

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animations)
- JavaScript (ES6+)
- LocalStorage لحفظ التقدم
- Web Speech API (للتعرف على النطق — مستقبلاً)

## المساعد الذكي

المساعد يعمل محلياً في المتصفح ويمكنه:
- الإجابة عن أسئلة حول اللغات
- تقديم نصائح دراسية
- وضع خطط تعلم
- تحفيز المتعلمين
- شرح كيفية استخدام الموقع
